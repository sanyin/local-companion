# local-companion

**把一个本地大模型，变成住在你电脑里的一个人。**

它不是一个聊天界面，是五件事：

| | |
|---|---|
| **记得住** | 记忆要你点头才生效，否掉的不会再提；同义会合并、久未用会降温、矛盾的会摆出来问你 |
| **会先开口** | 清早、久坐、夜深、久别，还有**你的事快到了**；有每日上限、有安静时段、默认沉默 |
| **看场合** | 闲聊 / 陪着你 / 办事 / 着急，四种状态决定语气、长度、能不能开玩笑 |
| **有边界** | 读写文件要确认，确认逻辑在代码里不在提示词里；说不出处就说没有；没有身体就直说 |
| **会自己动一点脑子** | 目标是对象、差值是触发、动作分五级；默认**只观察记录**，放权是配置里的事 |

> 没有账号、没有服务端、没有遥测。模型是你自己的，数据只在你机器上——删掉 `memory/` 就等于没存在过。

**适合谁**：愿意花半小时配一次模型、在意数据不外流、受不了"客服腔"的人。  
**不适合谁**：想要开箱即用的网页应用、想要多端同步、想要插件市场的人。

## 你需要什么

| | |
|---|---|
| 系统 | Windows 10 / 11（macOS、Linux 见文末「平台」） |
| Python | 3.9 以上，**安装时要勾 "Add Python to PATH"** |
| 模型 | 一个 GGUF 文件，8B 的 Q4 量化约 4.7 GB |
| 显存 | 6 GB 起步；不够就用更小的模型或纯 CPU 跑（慢） |
| 依赖 | **没有第三方库**。只用 Python 标准库 + tkinter（Python 自带） |

## 30 秒跑起来

```powershell
# 1. 起模型（这个窗口要一直开着）
llama-server -m 你的模型.gguf --port 8081 --jinja -np 1 -c 8192 -ngl 99

# 2. 配置（第一次运行会问你四个问题）
copy runtime\config.example.json runtime\config.json

# 3. 跑
python runtime\core.py     # 网页：http://127.0.0.1:7860
python runtime\pet.py      # 桌面球（可选）
```

Windows 上直接双击 `start.bat`，它会检查 Python、生成配置、问名字，然后把两样都拉起来。
推理跑在 llama.cpp 上，换任何 OpenAI 兼容接口的模型都行。详细步骤和参数解释在下面的「使用方法」。

装好之后是什么样：右下角一颗半透明的球，点一下弹面板，说话像发微信。
她主动开口的时候，球旁边会冒一个气泡——一天最多几次，你说话的时候她不插嘴。

## 它跟别的做法差在哪

| | 常见做法 | 这里 |
|---|---|---|
| 记忆存在哪 | 云端账号 / 向量库服务 | 你机器上的 SQLite，`sqlite3 memory/zero.db ".dump"` 就能全拿走 |
| 什么能进记忆 | 模型自己决定 | 候选 + 你点头；否掉的进黑名单，不再提 |
| 记忆会变脏吗 | 越存越多 | 同义合并、降温、归档、矛盾上报；**只降温不删除** |
| 怎么用记忆 | 全塞进上下文 | 混合打分 + 去冗余，固定 12 条 / 700 字预算 |
| 会不会自己动手 | 提示词里约定 | 动作分 A0–A5；不可逆动作在代码里锁死，不靠自觉 |
| 出问题怎么查 | 翻日志猜 | `journal.jsonl` 是 append-only 账本，每个动作带理由和层级 |

一句实话：这不是"给她装上灵魂"。是把"记得住、有分寸、不越界"做成结构，剩下的靠相处。

# 使用方法

## 第一步：装 llama.cpp

去 [llama.cpp 的 Releases](https://github.com/ggml-org/llama.cpp/releases) 下载
`llama-bXXXX-bin-win-vulkan-x64.zip`（NVIDIA 显卡用 vulkan 或 cuda 版都行），解压到任意目录。

打开一个 PowerShell 确认能跑：

```powershell
D:\llama\llama-server.exe --version
```

## 第二步：下模型

比如 [Qwen3-8B-Instruct](https://huggingface.co/Qwen/Qwen3-8B-Instruct-GGUF) 的 `Q4_K_M`。
放哪都行，记住路径。

## 第三步：起模型（这个窗口要一直开着）

```powershell
D:\llama\llama-server.exe -m D:\models\Qwen3-8B-Q4_K_M.gguf --port 8081 --jinja -np 1 -fa on -c 8192 -ngl 99
```

几个参数不是随便写的：

| 参数 | 为什么 |
|---|---|
| `--jinja` | **必须**。工具调用走 chat template，不加这个她不会用工具 |
| `-np 1` | 单 slot。框架的后台任务是"错峰"设计的，靠的就是这个 |
| `-fa on` | flash attention，省显存、快一点 |
| `-c 8192` | 上下文。低于 4096 会频繁截断记忆 |
| `-ngl 99` | 全部层放显卡。显存不够就调小，让它部分跑 CPU |

看到 `server is listening on http://127.0.0.1:8081` 就成了。

## 第四步：第一次启动

双击 **`start.bat`**。

它会依次做：检查 python → 生成 `runtime\config.json` → **问你四个问题** → 起编排和桌面球。

四个问题是：

```
她叫什么名字？（可以随时改）            [小七]
你常在哪座城市？（用来查天气）          [上海]
她说话该是什么样？（简短/温和/活泼/严肃） [简短]
你希望她更像什么？（朋友/秘书/搭档/长辈） [搭档]
```

回答完会生成 `runtime\personality.md`——**这是她的起点，不是成品**，后面可以一直改。

然后右下角出现一颗球。

## 第五步：说话

**点一下球**，弹出面板，直接打字。

```
你：今天要带伞吗
她：要。下午有雨，降水概率 70%。
```

能问什么：

- **关于今天**：「今天几号」「外面冷不冷」「有什么新闻」
- **关于你的文件**：「我 D:\作业 里有没有关于预算的文件」（前提是授权过，见下）
- **关于记忆**：「帮我记一下周三要交报告」「我上次说的那个项目是什么」
- **关于提醒**：「二十分钟后提醒我关火」
- **关于她**：「你叫什么」「你记得我什么」

第一次用建议先试这三句：`今天几号`（验证模型通了）、`帮我记一下明天要交表`（验证记忆）、
`/人格`（验证人格装上了）。

## 迷你命令

习惯打字的话，面板里这些也可以：

| 命令 | 干什么 |
|---|---|
| `/名字 新名字` | 给她改名（球上、窗口、提示词全都跟着变） |
| `/人格` | 看她的系统提示原文，并列出还缺哪几节（调人格时用） |
| `/记 内容` | 直接让她记住一句话（进"已生效"，不走待确认） |
| `/记忆` | 打开记忆窗口，收下 / 不要，点着用 |
| `/授权 路径` | 允许她读某个文件夹，比如 `/授权 D:\作业` |
| `/目录` | 看现在授权了哪些 |
| `/简报` | 今天的天气和要闻 |
| `/深思 问题` | 让她答两遍（草稿→挑错→重写），慢一点但更靠谱 |
| `/试 早`、`/试 夜`、`/试 坐` | 让她现在就主动说一句，看效果（不占当天次数） |
| `/新` | 开个新话题（只断上下文，不清屏幕） |
| `/帮助` | 命令速查 |

## 网页版

浏览器打开 <http://127.0.0.1:7860>。球适合说话，网页适合**改配置和批量处理**：

- **设置**：名字、城市、主动开口开关与上限、桌面感知开关
- **她能碰的目录**：授权 / 撤销
- **她记得的**：收下 / 忘掉
- **待确认**：一条条过

## 让她能读你的文件

出于安全，**默认她什么文件都读不到**。要显式授权：

```
/授权 D:\作业
```

或者在网页的「她能碰的目录」里填。

授权之后她能列目录、读文本、搜内容、写文件（写和删**每次都要你点头**）。
令牌、配置、记忆这几个文件永远读不到，就算你把整个盘授权了也一样。

## 三件需要你自己定的事

**1. 名字。** `config.json` 里的 `name`。改一处，球上的字、窗口标题、提醒弹窗、
系统提示里的自我介绍全都跟着变。三个入口等价：改文件、网页设置、`/名字 小七`。

**2. 她是谁。** `runtime/personality.md`。`personality.example.md` 是**模板，不是成品**——
里面有每一节该写什么、为什么写、常见错误，照着填。

**3. 模型。** `config.json` 的 `model_url`。

### 人格怎么调

改完文件**直接发下一句就生效，不用重启**。调之前先 `/人格`——

它会把系统提示原文摊开给你看（同时写到 `logs/prompt-preview.md`），并告诉你哪几节还缺。
**盲调是最浪费时间的。**

最常见的坑：在人格里写「不要说 X」，她会学着说 X。**只写正确的话。**

### 她会自己慢慢变

相处久了，她会发现你的口味（要多长、爱不爱被催、什么时候别说话），
把观察提成**候选**，等你点头。收下的进提示词，变成她的习惯；否掉的进黑名单，不会再提第二遍。

**人格是起点，相处才是长期调参。**

## 记忆是怎么挑的

以前的版本按记账顺序取前 40 条，超过 40 条以后新记的事永远进不去。
现在每一轮都重新挑：

```
分数 = 语义 × 0.45 + 字面 × 0.25 + 新近 × 0.15 + 用过 × 0.05 + 重要 × 0.10
```

- **预算**：最多 12 条 / 700 字，哪个先到就停。注入量不随记忆总量膨胀。
- **去冗余**：挑第二条起会跟已选的比，太像的扣分——不让 12 条说同一件事。
- **置顶**：永远在里面，不参与排序。
- **冷热**：久没被召回的记忆自己降温（只降温，不删除），排在后面。
- **中文检索**：索引的是字符 2-gram，不是原文。FTS5 默认分词器会把「我住在上海」
  当成一个词，搜「上海」是搜不到的——这个坑必须绕开。

没有向量模型也能跑：语义分为 0，其余权重照算；装了模型（`memory.model_id`）
就自动参与打分。索引坏了会退回纯字面匹配，不影响记东西。

### 它自己会变干净

每天空闲时跑一次整理：同义合并、降温、归档冷区、把互相矛盾的记忆摆出来问你
（**不自动裁决**）。所有动作都进 `journal.jsonl`，可以回放。

## 目标和差值：能动性的最小内核

这里要先把话说明白：**这不是"它会自己想做点什么"，是一套约束**。

| 层 | 是什么 | 默认 |
|---|---|---|
| 目标 | 「要达到什么状态」+ 可核对的判据 | 不动 |
| 差值 | 「按进度该到了，实际没到」 | 只记录 |
| 预测 | 「我猜这件事会怎样」+ 到期核对 | 只记录 |
| 动作阶梯 | A0 观察 → A4 可逆动作 → A5 不可逆 | **卡在 A0/A1** |

`agency_mode` 四档：

```json
"agency_mode": "observe"
```

- `off` —— 心跳都不跑
- `observe`（默认）—— 只算差值、只记日志、最多做点可逆准备，**不开口不动手**
- `propose` —— 可以提出方案等你点头
- `act` —— 可以对白名单内的路径执行可逆动作

A5（发消息、删东西、花钱）在任何档位都不会自动执行。这是代码里的硬约束，
不是提示词里的约定。

先跑 `observe` 一段时间，看 `/api/agency` 里的判断准不准，再决定放不放权。
**判断准确率没测出来之前给权限，就是拿你的真实环境做实验。**

## 出问题了

| 现象 | 多半是 | 怎么办 |
|---|---|---|
| 双击 `start.bat` 闪一下就没了 | 没装 Python 或没进 PATH | 重装 Python，勾 "Add Python to PATH" |
| 球出现了，说话没反应 | 模型没起，或 `model_url` 不对 | 看那个 llama-server 窗口还在不在；`start.ps1` 启动时也会提示 |
| 她说"我没有授权" | 还没授权目录 | `/授权 D:\你的文件夹` |
| 她说话像客服、太长 | 人格没写或写空 | `/人格` 看缺哪几节，补 `personality.md` |
| 她老主动说话，烦 | 上限设太高 | 网页设置里取消勾选，或 `config.json` 里 `proactive: false` |
| 端口被占 | 7860 或 8081 有别的程序 | 改 `config.json` 的 `port`，或换 llama-server 的 `--port` |
| 想让她忘掉一切 | —— | 删 `memory/` 里的文件 |
| 不想让她知道你开什么程序 | —— | 网页取消「允许她看你在用哪个程序」，或 `desk_watch: false` |
| 升级后 `memory/` 里多了 `zero.db` | 记忆换成了 SQLite | 正常。`memories.json` 仍在，用 `/导出` 或 `sync_json()` 可以写回去 |
| 她记的事"没进上下文" | 预算 12 条 / 700 字 | 置顶或提高重要程度；或者查 `/api/agency` 看检索 trace |

## 数据在哪

全在 `memory/` 和 `runtime/` 里，随时能读能删：

| 文件 | 是什么 |
|---|---|
| `memory/zero.db` | 记忆主库（SQLite，含索引、关系边、检索 trace） |
| `memory/memories.json` | 记忆的纯文本投影（导出/降级用，定时同步） |
| `memory/journal.jsonl` | 不可变账本：记了/确认了/忘了/合并了什么 |
| `memory/rejected.json` | 你否掉过的（防止再提） |
| `memory/preferences.jsonl` | 你的「收下 / 不要」，将来训抽取器用 |
| `memory/conversations.jsonl` | 最近 6 小时的对话 |
| `memory/reminders.json` | 提醒 |
| `memory/graph.json` | 关系网（从记忆派生，删了会自动重建） |
| `memory/agency.db` | 目标、预测、动作审计、预算计数 |
| `memory/gap_log.json` | 差值去重（同一目标七天内只提一次） |
| `memory/tick_state.json` | 心跳的 last_tick（睡眠后只补一次） |
| `runtime/personality.md` | 她是谁 |
| `runtime/config.json` | 设置 |

**备份就是复制 `memory/` 和 `runtime/personality.md`。**
换电脑带上这两样，她就连人带记忆一起搬过去了。

想回到纯文本版本：`config.json` 里设 `"memory_v2": false`，
先把 `zero.db` 用 `/导出` 写回 `memories.json`。

## 它不会做什么

- 不会上传你的任何东西。除了你主动要的天气/新闻/搜索，没有对外请求。
- 不会记得你没同意的事。候选记忆先进「待确认」，你点头才算数。
- 不会假装有身体。看不到屏幕内容、点不了外卖——它会直接说。
- 不会自己动你的东西。默认 `agency_mode: observe`，只观察记录；
  可逆动作要显式开 `act` 且限定白名单；不可逆动作永远要你点头。
- 不会因为"很久没说话"就编一件关心你的事。开口必须有由头，由头必须写在日志里。

## 架构

```
      桌面球 / 网页 (SSE)
              │
              ▼
        core.py   ── 状态 → 提示 → 工具 → 流式 → 挂出处
       ╱   │   │   ╲
 persona memory tools  web
  四种状态  记忆   工具+确认门  天气/新闻/搜索
              │
   ┌──────────┴──────────┐
 proactive tasks desk graph      ← 说话闸门 / 后台 / 眼睛 / 关系网
 memdb memrank memlinks          ← 记忆存储 / 挑选 / 边与退化
 agency goals gap predictions ticker   ← 目标 / 差值 / 预测 / 心跳
```

| 模块 | 职责 |
|---|---|
| `core.py` | HTTP + SSE 编排，唯一知道"一次对话长什么样"的地方 |
| `llm.py` | llama.cpp 客户端（流式 / 一次性 / 工具调用），纯标准库 |
| `persona.py` | 状态判定 + 每种状态的语气、温度、长度 |
| `memory.py` | 老版本记忆（JSON），保留作降级路径 |
| `memdb.py` | 记忆主库：SQLite + 2-gram FTS + 迁移 + 同签名 API |
| `memrank.py` | 挑记忆：混合打分、去冗余、字符预算、trace（纯函数） |
| `memlinks.py` | 类型化边 + 退化闸（合并 / 降温 / 归档 / 报矛盾） |
| `goals.py` | 目标对象 + 可核对判据（文件、记忆、只能问人） |
| `gap.py` | 差值：预期 vs 观测，带去重、冷却、冷启动规则 |
| `predictions.py` | 预测账本 + 校准因子（估高了会打折） |
| `agency.py` | 动作阶梯 A0–A5 + 三档预算 + 审计日志 |
| `ticker.py` | 自持心跳：可注入时钟、睡眠后只补一次、异常不停 |
| `tools.py` | 工具注册表 + 权限 + 待确认凭据 |
| `web.py` | 联网：天气、要闻、搜索（无 API key） |
| `proactive.py` | 主动开口的闸门：什么时候说、一天几次、什么时候闭嘴 |
| `tasks.py` | 后台队列（模型只有一个 slot，所以是错峰不是并行） |
| `desk.py` | 眼睛：知道你在哪个程序上（Windows） |
| `graph.py` | 关系网：从已确认记忆派生实体和关系 |
| `setup.py` | 第一次启动的四个问题 |

## 平台

- **Windows**：完整支持（桌面球、桌面感知、一键启动）
- **macOS / Linux**：核心、网页、工具可用；`desk.py` 的窗口感知是 Win32 实现，
  在别的平台上会返回"看不见"，不会崩。手动跑 `python runtime/core.py` 即可。

## 隐私边界

| 内容 | 在哪 | 会上传吗 |
|---|---|---|
| 你的人格设定 | `runtime/personality.md` | 不会，这是你的 |
| 记忆 | `memory/zero.db`、`memory/memories.json` | 不会 |
| 对话 | `memory/conversations.jsonl` | 不会 |
| 目标与预测 | `memory/agency.db` | 不会 |
| 令牌 | `runtime/.zero_token` | 不会 |

`.gitignore` 已经把这些排掉了。这个仓库本身是用白名单生成的，物理上不含这些文件。

## 关于"忠诚"

忠诚不是提示词能给的东西——模型没法保证"永远"。
这个框架能给的，是把忠诚变成**结构**：

- 没有遥测、没有后门。除了你自己看得见的三个联网工具，没有对外请求。
- 数据是你机器上的文件（SQLite + JSONL）。你能读、能带走、能删，
