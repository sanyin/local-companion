# local-companion

一个**本地优先**的个人助理框架。模型由你选，人由你定，数据只在你机器上。

它不是一个聊天界面，是一套"怎么把一个本地大模型变成一个人"的结构：

- **记得住人**：记忆要你点头才生效，否掉的不会再问一遍。
- **看场合**：闲聊 / 陪着你 / 办事 / 着急，四种状态决定语气、长度、能不能开玩笑。
- **会先开口**：早报、久坐、夜深、久别，四种由头，有上限、有安静时段。
- **有手也有边界**：读写文件要确认，确认逻辑在代码里，不在提示词里。
- **不编**：说不出处就说出不出处；答应的提醒必须真的建。

推理在 llama.cpp 上跑，默认 Qwen3-8B，换任何 OpenAI 兼容接口的模型都行。

## 三件需要你自己定的事

**1. 名字。** 框架里的名字只是一个占位，**使用者可以改成任何想叫的名字**——
`config.json` 里的 `name`。改一处，球上的字、窗口标题、提醒弹窗、系统提示词全都跟着变。
也可以在球里直接 `/名字 小七`，或者网页设置里改。

**2. 她是谁。** `runtime/personality.example.md` 是**模板，不是成品**。
里面有每一节该写什么、为什么写、常见错误，照着填就行。复制成 `personality.md`。

**3. 模型。** `config.json` 的 `model_url` 指向任何 OpenAI 兼容接口。

### 人格怎么调

改完文件直接发下一句就生效，不用重启。调之前先 `/人格`——
它会把系统提示原文摊开给你看（同时写到 `logs/prompt-preview.md`），
并告诉你哪几个小节还缺。**盲调是最浪费时间的。**

最常见的坑：在人格里写「不要说 X」，她会学着说 X。只写正确的话。

### 她会自己慢慢变

相处久了，她会发现你的口味（要多长、爱不爱被催、什么时候别说话），
把观察提成**候选**，等你点头。收下的进提示词，变成她的习惯；
否掉的进黑名单，不会再提第二遍。

**人格是起点，相处才是长期调参。**

## 它不会做什么

- 不会上传你的任何东西。除了你主动要的天气/新闻/搜索，没有对外请求。
- 不会记得你没同意的事。候选记忆先进"待确认"，你点头才算数。
- 不会假装有身体。看不到屏幕、点不了外卖——它会直接说。

## 架构

```
      桌面球 / 网页 (SSE)
              │
              ▼
        core.py   ── 状态 → 提示 → 工具 → 流式 → 挂出处
       ╱   │   │   ╲
 persona memory tools  web
  四种状态  记忆   工具+确认门  天气/新闻/搜索
              │
        proactive  tasks  desk  graph
         主动开口   后台   眼睛  关系网
```

| 模块 | 职责 |
|---|---|
| `core.py` | HTTP + SSE 编排，唯一知道"一次对话长什么样"的地方 |
| `llm.py` | llama.cpp 客户端（流式 / 一次性 / 工具调用），纯标准库 |
| `persona.py` | 状态判定 + 每种状态的语气、温度、长度 |
| `memory.py` | 长期记忆、候选记忆、对话流水 |
| `tools.py` | 工具注册表 + 权限 + 待确认凭据 |
| `web.py` | 联网：天气、要闻、搜索（无 API key） |
| `proactive.py` | 主动开口的闸门：什么时候说、一天几次、什么时候闭嘴 |
| `tasks.py` | 后台队列（模型只有一个 slot，所以是错峰不是并行） |
| `desk.py` | 眼睛：知道你在哪个程序上（Windows） |
| `graph.py` | 关系网：从已确认记忆派生实体和关系 |

## 快速开始

```bash
# 1. 起模型（任何 OpenAI 兼容的本地服务都行）
llama-server -m your-model.gguf --port 8081 --jinja -np 1 -ngl 99

# 2. 配置
cp runtime/config.example.json runtime/config.json
cp runtime/personality.example.md runtime/personality.md   # 然后改成你自己的人

# 3. 跑
python runtime/core.py           # 网页版 http://127.0.0.1:7860
python runtime/pet.py            # 桌面球（可选）
```

Windows 上直接双击 `start.bat`。

## 关于"忠诚"

忠诚不是提示词能给的东西——模型没法保证"永远"。
这个框架能给的，是把忠诚变成**结构**：

- 没有遥测、没有后门。除了你自己看得见的三个联网工具，没有对外请求。
- 数据是纯文本 JSON。你能读、能带走、能删。
- 没有服务端。不存在"作者关掉服务器你就用不了"。
- 许可证允许你 fork。作者也不能远程改你的。
- 人格和行为全在明文的 `.md` 和 `.py` 里，没有黑箱。

**一个模型说"我永远忠于你"是没有约束力的；能看懂、能拿走、能换掉，才是。**

## 隐私边界

| 内容 | 在哪 | 会上传吗 |
|---|---|---|
| 你的人格设定 | `runtime/personality.md` | 不会，这是你的 |
| 记忆 | `memory/memories.json` | 不会 |
| 对话 | `memory/conversations.jsonl` | 不会 |
| 令牌 | `runtime/.zero_token` | 不会 |

`.gitignore` 已经把这些排掉了。导出的仓库用白名单生成，物理上不含这些文件。

## 平台

- **Windows**：完整支持（桌面球、桌面感知、一键启动）
- **macOS / Linux**：核心、网页、工具可用；`desk.py` 的窗口感知是 Win32 实现，
  在别的平台上会返回"看不见"，不会崩。
